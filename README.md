# Chat App

A full-stack real-time chat application built with React and Express, featuring user authentication, real-time messaging, and customizable user settings.

## Features

- Real-time messaging with Socket.IO
- JWT-based authentication (sign up / login)
- User profiles 
- User settings management
- Modern UI with Tailwind CSS
- Responsive design


## Tech Stack

**Frontend:**
- React
- Tailwind

**Backend:**
- Express.js
- Node.js
- PostgreSQL


## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/damijanaku/chat-app.git
cd chat-app
```
2. Move into inner directory on server and client and do npm install
```bash
npm install
```

4. Create PostgreSQL DB and run migrations

5. Create .env files on server side

6. To start app use on server and client side (inner dir chat-app)
```bash
npm run dev
```
